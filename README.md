# 任务栏控制条（taskbar-controls）

给 Folia 做一个贴在**屏幕底部任务栏左下角**的透明控制条，替代壁纸模式下没法点的底部控制栏：

- 背景完全透明，只显示图标与文字（带阴影，保证深浅壁纸下都看得清）
- 鼠标可直接点击：上一首 / 播放暂停 / 下一首 / 循环 / 喜欢 / 静音 / 音量 / 打开播放器侧边面板 / 返回一层
- 右侧一个箭头按钮：**展开**出第二排（歌曲标题、进度条、可点跳转、音量滑杆），再点收起
- 默认收起状态就占任务栏一条，展开时窗口向上长、底边不动
- 宽度、距屏幕左边、距屏幕底边、整体不透明度、展开是否显示标题，都能在「设置 → 模组 → 任务栏控制条」里改，改完自动重新贴边
- 命令面板里有一条「任务栏控制条：贴回左下角」，控制条被别的置顶窗口盖住时用它复位

## 安装

1. Folia 里打开「设置 → 模组 → 模组系统」；
2. 把 `taskbar-controls.zip` 拖进模组面板，或把 `taskbar-controls` 文件夹放进 `%APPDATA%\Folia\mods`；
3. 在模组面板启用「任务栏控制条」，按提示在原生窗口里确认；
4. 命令面板执行「任务栏控制条：贴回左下角」即可看到它。

## 需要知道的限制

- **不是真的插进任务栏**：任务栏属于 explorer.exe，普通程序无法在其中绘制。这里是一个「无边框 + 透明 + 置顶（screen-saver 层级 + relativeLevel 1）」的独立窗口叠在任务栏左侧上方，视觉上和任务栏连成一片。
- **会遮住该区域的任务栏按钮**：窗口是矩形，透明处仍然拦截鼠标。所以默认宽度 320、靠左 10px；Windows 11 左端是小组件/搜索区，冲突就把「距屏幕左边」调大，或把宽度调窄。
- **窗口必须可获得焦点**：Windows 上如果把窗口做成 `focusable: false`（即 `WS_EX_NOACTIVATE`），Chromium 只会把鼠标**移动**转发给渲染进程，**按下/抬起**会被丢掉——表现就是悬停有反应、点下去没反应。所以这个窗口用 `focusable: true`。代价是点它的瞬间焦点会从当前程序切走（点完不影响别的程序运行）。
- **全屏程序会自动让位**：模组每 0.8 秒检查一次前台窗口（通过 Folia 自带的 koffi 调 user32 的 `GetForegroundWindow` / `GetWindowRect` / `GetClassNameW`），只要前台窗口的矩形把整块屏幕铺满（误差 3px 内），就判定为全屏并把控制条 `hide()`；全屏退出后自动 `showInactive()` 回来。桌面（`Progman`/`WorkerW`）、任务栏、Windows 输入法宿主会被跳过，不会误隐藏。如果 Folia 的 koffi 不可用，这项功能会自己关闭并写日志，不影响其他功能。
- **整条可点**：全透明像素在 Windows 上会穿透点击，所以底下垫了一层肉眼看不见的极低透明度底色，按下按钮之间的空白也能点到（只是空白处没有动作）。
- 任务栏如果是自动隐藏，控制条会浮在那条隐藏带上，鼠标移到底部时它不会自己跟着弹出。
- 任务栏放在屏幕顶部/左右侧时，控制条会贴到对应一边的底部，但左下角布局只在底部任务栏时最准确。
- **原生播放器控件（底部进度胶囊、侧边面板圆钮）藏不掉**：Folium 只把进度条内部的 `progress.root/track/fill/thumb/time/duration` 列为公开可改对象，胶囊容器与面板按钮没有公开标识，模组无法安全隐藏它们。Folia 自己有一个设置 `autoHidePlayerChrome`（「自动隐藏播放控件」）和 `player_chrome_visibility_mode`（`always-visible` / `auto-hide` / `always-hidden`），要隐藏请用宿主自带开关。
- 模组改动文件后会被自动禁用，需要重新启用并确认（官方安全机制）。

## 权限

- `playback.read`：读取播放状态快照
- `playback.control`：播放/暂停、切歌、循环、喜欢、音量、跳转

## 结构

| 文件 | 作用 |
| --- | --- |
| `mod.json` | 模组清单 |
| `main.cjs` | 主进程：创建/定位/置顶透明窗口，转发点击与状态 |
| `client.mjs` | 渲染进程：注册设置与命令，执行播放动作，推送状态 |
| `bar.html` | 控制条界面（透明背景、图标与文字、展开逻辑） |
